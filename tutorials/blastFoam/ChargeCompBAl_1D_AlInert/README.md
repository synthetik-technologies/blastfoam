# 1D Linear ChargeCompBAl

## Notes

This is a 1D linear version of the ChargeCompBAl case. 
The domain is 0.2m long along the X-axis.
A 0.14m charge is located between X=0.01m and X=0.15m, surrounded by air.
The charge is initiated at X=0.01m.
All pressure boundaries are set to zeroGradient.

Run with:
./Allrun
